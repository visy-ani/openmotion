OpenMotion Architecture Blueprint

OpenMotion 跨端 MCP 架构与系统边界全景图

单核 5 层架构 · Web 与 Mac/Win/Linux 桌面端共用 React SPA · Streamable HTTP /mcp 与本地 Stdio 统一契约

调用链路：
LAYER 1 交互入口层 · 统一前端 SPA & 3 端桌面外壳
Web 与 Electron 共享 studio/ React 页面，只通过 PlatformHost 适配宿主差异
LAYER 2 控制平面网关 · HTTP API / SSE / Origin 守卫 / Sidecar 托管
保留 /api /motion-api /design-api /mcp 前缀，不直接暴露内部进程
LAYER 3 统一 MCP Hub 与自动化总线 · Stdio / Streamable HTTP / Triggers
外部与内部 Agent 通过完全一致的 34 个 openmotion_* 公开工具契约接入
LAYER 4 Agent 编排与计算平面 · 本地直连 / 出站 NAT 桥接 / 云端 Agent / 外部宿主
控制面不入站穿透用户电脑，只允许用户本地 Bridge 主动出站长连接拉取任务
LAYER 5 共享域服务核、批量内容优化、工作区持久化与外部云边界
单一能力实现被 UI、MCP 与 Trigger 共用；云端部署与用户密钥严格隔离开源仓库
